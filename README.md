# Fincord
Pachet de pluginuri pentru Discord pe Android, pentru loaderele Revenge / Kettu / Bunny (Vendetta API).

## Instalare
1. Instalează **Revenge Manager** (github.com/revenge-mod/revenge-manager) și dă Install.
2. Pune acest repo pe GitHub, apoi activează **GitHub Pages** (Settings → Pages → branch main).
3. În Discord: Settings → Plugins → `+` → lipește `https://<user>.github.io/fincord/plugins/<Nume>/`.

## Pluginuri
| Plugin | Ce face |
|---|---|
| MessageLogger | mesajele șterse rămân pe chat, cu roșu; cele editate arată textul vechi |
| CustomPresence | activitate custom pe categorii: Playing, Streaming (YouTube/Twitch), Listening (Spotify), Watching (Crunchyroll/YouTube), Competing, Roblox, cu nume, detalii, link |
| BadgeMaxxer | arată toate badge-urile pe profilul tău (doar tu le vezi, local) |
| PlatformSpoof | alegi platforma cu care apari: PC, Phone, VR, Web (repornește aplicația) |

Folosirea client modat e contra regulilor Discord, riscul e al tău.
